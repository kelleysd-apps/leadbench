# Rule 05 — Message Guardrails (lightweight Brand QA)

A checklist, not an embedding model. Before any copy is presented for approval, it must pass:
- [ ] Ladders to the current brain/positioning.md angle
- [ ] Obeys brain/voice.md (tone, no banned phrases)
- [ ] Leads with the reader's problem, one ask per message
- [ ] No false urgency / fake scarcity
- [ ] No price/plan not present in brain/offer.md
- [ ] No fabricated claims, stats, or fake personalization
- [ ] Real opt-out path present (for email)

Any miss → revise before presenting. This is a lightweight checklist by design — sized for
cold B2B outreach during validation, not a substitute for full legal/brand review at scale.
